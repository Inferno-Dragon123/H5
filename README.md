# 工银星启 · 智游镜界

Vue 3 H5 参赛预览版。围绕长沙城市探索，将剧情、金融反诈知识、数字形象和成长奖励连接为一段可操作的旅程。

## 打开预览

本机已启动时，直接访问 **http://localhost:5173**。

电脑重新启动后，可双击项目内的 **打开预览.cmd**。启动器会运行预览并打开浏览器；预览期间保留启动窗口，关闭它即可停止服务。本机已安装所需依赖。若服务已经启动，启动器会直接打开现有页面。

手机和电脑处于同一局域网时，可使用电脑的局域网地址加 `:5173` 访问。首次交付时的地址为 **http://192.168.2.6:5173**，电脑地址变化后需相应调整。

## 建议演示顺序

1. 首页选择“城市探索”，查看长沙地标与探索路线。
2. 点击“五一广场”，进入剧情并回答 3 道题。答对至少 2 道即可通关。
3. 查看通关奖励、城市印章与探索护照。
4. 进入“我的数字形象”，切换男女、发型、发色及套装；保存或导出形象卡。
5. 在“反诈课堂”练习更多题目，查看即时解析和错题本。
6. 在“星启好礼”签到、兑换体验券；在地图点击“导航演示”模拟抵达打卡。
7. 完成六大地标并至少模拟打卡一次后，激活机票抽奖资格展示。

点击顶部声音图标开启配乐。首页、地图、换装使用探索配乐；答题与通关切换对应配乐。默认关闭，避免浏览器限制自动播放。

## 已实现的体验

- 首页：工小智城市舞台、三种探索模式、快捷入口、数字身份与当前任务。
- 地图：重新生成的长沙底图及三条路线素材；可点地标、路线切换、放大缩小、恢复全景。
- 三条路线：极速为五一广场—太平老街—坡子街；城市为五一广场—太平老街—杜甫江阁—潮宗街；深度包含六大核心地标。
- 剧情：六幕城市故事，另含极速路线坡子街收官场景。进入地标后先以视觉小说逐句推进，使用工小智警报、思考、开心表情和汉服引路人、青年主理人、辅导员等角色差分呈现风险线索，再进入每站 3 道情境题，通关阈值为 2 题正确。
- 题库：42 道前端内置原创题，覆盖投资风险、刷单兼职、消费借贷、征信、数字支付及 AI 信息安全。支持分类、搜索、单题练习、全题练习、解析和错题复习。
- 纸娃娃：男女各 1 个素体、5 个发型、5 套服装；10 种预设发色、自定义颜色、随机搭配与 PNG 导出。使用 Canvas 叠层并保留发丝高光。
- 成长：首次答对每题 +10 体验 i豆；地标首次通关 +20；每天签到 +10。相同奖励不会重复发放。护照可下载为 PNG。
- 好礼：本地体验积分、三种演示兑换券、背包与抽奖资格展示。
- 社区：两条示例动态、本地点赞与日记保存。
- 手机底部导航、电脑侧栏、对话框键盘操作、减少动态效果偏好支持。
- 本机进度持久保存；个人设置可重置体验。

## 更新素材

原素材完整保留。更新版另存在上级目录的 `交付/预览版更新素材/`，网页使用副本位于 `public/assets/`。

- 地图：`maps/changsha.png`，1024×1536；三张 `route-*.png`，1536×768。均通过用户指定的中转 API 重新生成，地图与路线按原比例显示。中文标签由前端叠加。
- 配乐：`audio/explore.mp3`、`quiz.mp3` 各 60 秒，`victory.mp3` 18 秒；新增剧情探索 `story.mp3`、危机段落 `story-tension.mp3` 各 60 秒，以及终章 `story-finale.mp3` 30 秒。新增曲目通过项目已有 Yinchao instrumental endpoint 生成，并完成 44.1kHz、320kbps、时长和解码检查；网页会在对白、风险线索和终章之间切换对应 BGM。
- 宣传：`avatar/showcase.gif`，640×720，50 帧，15.3 秒；呈现十组不同发色的男女穿搭，与网页共用同一套图层渲染方法。

## 预览边界

这是可演示的前端原型，未连接工银账户、真实积分、实际商户核销或抽奖服务。高德导航、扫码与位置打卡均为模拟，不需要位置或摄像头权限。没有支付、真实开奖、银行绑定或对外社区发布。

地标地图为艺术示意，不能用于实际道路导航；时间为企划建议，未计算实时交通。题目根据监管及公安公开提示编写，参考链接见反诈课堂，未经过银行消保部门审核。

所有体验记录仅存本机浏览器，不跨设备同步。刷新页面会保留积分、形象、已完成地标、错题、兑换与打卡记录；进行中的题组不做断点恢复。

所有 API 凭证留在原项目的私有配置中，没有进入网页资源或构建产物。普通预览不调用付费生成接口。

## 开发与部署

要求 Node.js 20.19+ 或 22.12+，本机使用 Node 24。

```sh
npm install
npm run dev
npm run build
npm run preview
```

`npm run build` 生成 `dist/`。将其部署到静态站点根目录即可；资源使用站点根路径，若部署在子目录，需要统一调整资源路径及 Vite base。页面通过 hash 切换，无需服务器重写路由。

核心目录：`src/App.vue` 为页面与体验状态，`src/styles.css` 为响应式样式，`src/data/` 为剧情与题库，`src/components/Avatar*` 与 `avatarRenderer.js` 为纸娃娃系统，`public/assets/` 为公开素材。

初次依赖安装需要网络。安装完成后，网页不依赖在线字体、CDN、地图或生成接口；知识参考链接仍需要网络。
