# 工银星启 · 智游镜界

Vue 3 H5 参赛演示。从模拟银行首页的活动入口进入，用视觉小说、关卡答题、数字形象和成长奖励串联长沙探索。

## 预览与开发

线上：<https://h5-mu-bay.vercel.app>。本机开发：<http://localhost:5173>。

要求 Node.js 20.19+ 或 22.12+。首次运行 `npm install`，随后执行：

```sh
npm run dev
npm run build
npm run preview
```

`build` 生成静态 `dist/`，`preview` 默认端口 4173。GitHub main 自动部署到 Vercel；资源使用站点根路径。普通体验不需要生成 API、后端或 CDN。

## 演示顺序

1. 查看模拟开屏与银行首页，点击智游镜界活动入口。
2. 在“地标故事”选择路线，按章节进入故事。
3. 点击对话框继续，查看人物动作、差分和场景变化；点调查卡检查线索，作出剧情选择。
4. 每站挑战 3 道题，至少答对 2 道通过。查看解析与成绩后继续通关后日谈；未通过时听取提示并重试。
5. 在地图点击“扫码打卡 · 导出证书”（手机也可点击底部“打卡”）：选择点位 → 开始扫码演示 → 确认识别结果 → 生成并下载证书。
6. 换装、染发、导出形象卡或兑换体验权益；在“我的 → 我的打卡证书”重新导出保存的证书。

默认关闭声音。声音按钮开启配乐，章节入口只播一次开场语音，不逐句重复。音乐随场景切换并淡入淡出。

## 扫码打卡与证书

二维码由 `qrcode` 在前端生成，内容为本站地标链接，例如 `https://h5-mu-bay.vercel.app/?checkin=wuyi#map`。可用另一台手机真实扫码打开；本页面的“开始扫码演示”通过扫描动画识别同一个链接，无需摄像头或定位权限。识别后仍需点击确认，切换点位或关闭弹窗不会保存打卡。

确认后生成 1080 × 1440 PNG 打卡纪念证书，包含昵称、路线进度、点位、首次打卡时间及纪念编号。重复打卡不增加记录或 i豆，同路线同地标保留原证书。当前路线所有关卡通关且所有点位打卡后，再次确认可升级为路线结营证书。扫码本身不算关卡通关。

证书元数据保存到本机浏览器，可从“我的打卡证书”重新生成图片与下载。手机若未自动下载，可长按证书预览保存。原探索护照保留。旧版打卡数组与积分/通关记录兼容，旧打卡没有准确时间，首次使用新版扫码时才生成带时间的记录。

## 视觉小说

使用开源 **Monogatari 2.8.0**（MIT），以同源静态 iframe 嵌入 Vue。官方发行文件及许可保留在 `public/novel/vendor/`，引擎按章节加载。

- 7 章、29 个场景段、154 条对白/旁白/交互节点、8 次情境抉择。节点数包含路线限定对白与失败分支，单条路线不会显示全部。
- 9 张独立背景、6 张新 NPC 差分，加上工小智现有普通、开心、思考和警报差分。
- 多人物同屏、差分淡变、入场、点头、躬身、递物、前倾与消散；镜头、转场、调查卡、来电、i豆雨、影像碎裂及城市复明。
- 原生打字机、选项、回看、自动阅读及本机存读档。答题期间暂停小说并禁用存档，保持 iframe 挂载。
- 手机调查卡默认折叠，点“查看线索”展开；支持 320px 及以上布局与减少动态效果偏好。

|---|---|---|
| 极速 | 五一广场 → 太平老街 → 坡子街 | 坡子街 |
| 城市 | 五一广场 → 太平老街 → 杜甫江阁 → 潮宗街 | 潮宗街 |

依据企划书的事件和原话适配，梗概处补衔接对白，并修正原稿的路线终点矛盾。省博保留假辅导员索要 5000 元押金、核验、影像崩解和复明，但判断依据为独立联系本人及核对活动/资金要求，不把微表情当作可靠的 AI 识别方法。胜利演出均在答题通过后播放。

独立“反诈课堂”、练习入口和错题本已移除。旧 `#classroom` 链接转到故事。42 道前端题库保留用于章节挑战，保留答案解析及知识参考链接。

## 状态与演示边界

首次答对每题 +10 i豆，地标首次通过 +20，每天签到 +10；奖励不重复发放。积分、形象、印章、兑换和打卡记录存本机浏览器；小说存档按章节/路线区分，不跨设备同步，答题中不存档。

纸娃娃系统保留男女素体、各 5 发型及 5 套服装、染色、随机搭配与 PNG 导出。手工修正的 `female-hair-4.png` 保持原样。

银行入口、券包、核销、导航、扫码、积分及抽奖均为参赛模拟。地图不能用作实际道路导航。没有真实支付、账户绑定、商户发券、定位或对外社区发布。生成凭证不进入网页或构建产物。

## 修改位置

- `src/App.vue`：页面、答题、积分与路线衔接。
- `src/components/VisualNovel.vue`：iframe、消息验证、章节结束与音频桥。
- `public/novel/story.json`：剧情、差分、动作、场景及分支。
- `public/novel/runtime.js`：编译 Monogatari 标签与选择。
- `public/novel/theme.css`：舞台、调查卡、转场及特效。
- `src/audio.js`：配乐、音效、环境声。
- `src/data/questions.js`：题库。
- `src/checkIn.js`：二维码链接校验、打卡记录与结营资格。
- `src/components/CheckInScanner.vue`：点位二维码、扫码动画与识别确认。
- `src/components/ExplorationCertificate.vue`、`src/certificateRenderer.js`：证书预览与 PNG 导出。

引擎维护说明见 `docs/visual-novel.md`。
